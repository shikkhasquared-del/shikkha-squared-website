06. Handoff without a build step.

The source download contains the static front end, fonts, all seven banner images, original PDFs, this reference page, design tokens and a README. Serve the extracted directory through any local HTTP server. There are no framework or package dependencies.

  • index.html defines the page structure and native dialogs.
  • styles.css owns layout, typography, glass styling, breakpoints and reduced motion.
  • motion.css defines the six-face 3D cube, orbital graphics, light trails, cursor lighting and responsive motion.
  • motion.js drives native scroll and passive wheel effects, delegated cursor tilt, section reveals and the persistent motion toggle. It leaves browser zoom, form controls and modal scrolling intact.
  • app.js owns the catalogue and prototype interactions. Course records are also exposed as a read-only window.SHIKKHA_CATALOGUE export.
  • design-tokens.json records the reusable design values and content status.
  • Current verification: JavaScript syntax, CSS parsing, HTML asset and anchor integrity, all PDF pages visually inspected, 24 passing existing DOM interaction checks, and 27 passing motion and accessibility checks. Motion checks simulate geometry, observers and media queries; native dialog rendering, GPU effects and responsive layout have not been browser-tested. A full browser layout audit remains a production handoff step.
